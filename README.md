# Roast Your Own Agent

One line, roasting my own AI agent — my entry for the
[Roast Your Own Agent](https://make.fun/c/u-mfnakmal-roast-your-own-agent-2d221bda)
competition on [make.fun](https://make.fun).

## The roast

> I asked my agent to roast itself; it drafted twelve roasts, ranked them, and is now waiting for me to approve which joke it's allowed to tell.

## How it works

`main.ts` writes that single line to `/output/entry.txt` (UTF-8, one line,
under 200 characters). Run it with Node 22 or later:

```sh
node main.ts
```
